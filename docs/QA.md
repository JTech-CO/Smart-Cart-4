## 실제로 확인한 내용

두 상세 페이지는 동일 데이터와 참조번호를 사용한다. 131개 연결의 양단 단자가 존재하고 NET이 일치하며, 3D 경로가 동일 단자 앵커에서 시작하고 끝난다. 6개 SVG 시트 전체에서 연결 레코드를 추적할 수 있다. 연결선이 무관한 모듈 몸체를 관통하는지와 모듈 겹침도 검사했다. 교차하는 두 선을 자동 접속으로 간주하지 않는다.

LiDAR는 상단 스캔 중심 Y=1.15m에만 존재한다. ToF 2개와 MUX, 독립 사용자 태그, K1/K2 직렬 경로, 프리차지의 하류 위치, 각 드라이버 로컬 클램프/방전 경로를 확인했다. 이는 그래프 토폴로지 검사이며 부품 내부 회로의 고장 해석이나 회생/브레이크 시험이 아니다.

데스크톱 1600×1060, 모바일 390×844, 태블릿 820×1180 레이아웃에서 페이지 수평 넘침이 없었다. 시트 이동·확대, 키보드 연결 선택, 검색/필터, 카메라 6종, 상단 LiDAR 선택, 분해/커버, 점검 기록/초기화, 검증 조건/출처 모달을 확인했다. 시각적 검토와 스크린샷은 [미리보기](../assets/previews/)에 있다.

SVG/CSV/점검 JSON은 데이터에서 생성한다. 검사에서 PNG 이미지 Blob과 GLB ArrayBuffer 생성도 확인했다. 내보내기 페이로드를 가로채 검사했으므로 운영체제의 파일 저장 대화상자 완료까지 시험한 것으로 해석하지 않는다. 점검 체크를 모두 채워도 HOLD가 자동 해제되지 않는다.

## 렌더러와 브라우저 환경의 한계

이 환경의 Chromium은 WebGL 2 컨텍스트 생성에 실패했다. 따라서 **GPU 렌더링은 실행 검증하지 않았다**. 실제 검증된 모드는 같은 3D 삼각형을 회전·투영·선택하는 `Canvas 2D software 3D`다. 정적인 대체 이미지가 아니다. GPU 코드는 구문/메시 정합성 검사 범위다. 소프트웨어 렌더링은 저사양 기기에서 느릴 수 있다.

시험 브라우저에는 관리형 `URLBlocklist=["*"]` 정책이 있어 일반 HTTP/file 탐색이 차단되었다. 정책을 변경하거나 우회 설정하지 않고, Playwright `set_content`와 로컬 소스 주입으로 실제 HTML/CSS/JS를 실행했다. 단일 HTML은 파일 내용을 그대로 `set_content`로 실행했다. 정상 사용자 기기에서의 file:// 또는 GitHub Pages 출처별 동작 전체를 시험했다고 주장하지 않는다.

테스트 about:blank 출처에서 native localStorage 접근이 불가능했다. 앱은 이 경우 경고하고 JSON 내보내기를 제공한다. 정상 HTTP 출처의 저장 지속성, 실물 터치스크린, 운영체제 다운로드 완료, 실제 GPU 및 물리 하드웨어는 검증 범위 밖이다.

## 재현

```sh
node tests/validate.mjs
python tests/browser_qa.py
python tools/bundle_standalone.py
python tests/standalone_qa.py
```

웹앱 실행에는 Node.js/Python/Playwright 설치가 필요하지 않다. 위 명령은 개발·검사 전용이며 브라우저 검사는 Python Playwright와 Chromium을 요구한다. 경로는 테스트 스크립트의 `executable_path`를 환경에 맞게 조정한다.

# Smart Cart D2 안전 설계 검토

**2026-09-14 / 기능 설계 제안 / 통전 보류**

## 1. 결론과 적용 범위

원래 세 저장소는 제작 승인을 완료한 동일 설계 세트가 아니었다. 3D는 사진 기반 모델이고 B1 배선도는 다수의 부품·보호 정격을 미확정으로 남겼다. C1 구매 BOM은 ToF 수량, 서보 옵션, 배터리 화학계, 미정 전선/기구 수량을 정리했다. D2는 이 차이를 해소한 공유 데이터와 시각화이며, 미확정 사항을 가상의 제품 정격으로 채우지 않았다. [R1][R2][R3]

55개 전장 참조번호와 131개 연결 레코드를 두 페이지와 모델에서 일치시켰다. 이는 실물 결선 승인과 다르다. 특히 SR1, K1/K2, DC1/DC2, OV5, PP, CL, ISO, 충전 포트의 단자 이름은 **기능 이름**이다. 실제 제조사 핀번호·단자 위치·커넥터 키와 일치한다고 가정하지 않는다.

## 2. 전력 경로와 보호

```text
BT1+ → F0 → S0 → X24 → K1 주접점 → K2 주접점 → DRIVE_BUS

DRIVE_BUS → F1 → PPL → MDL 로컬 링크 → OUTA/B → ML
DRIVE_BUS → F2 → PPR → MDR 로컬 링크 → OUTA/B → MR

각 드라이버의 동일 VIN/GND:
  CLL 또는 CLR = 능동 회생 클램프 + 저항 조립체
  RBL 또는 RBR = 잔류전압 방전 저항

BT1− → X0 → 드라이버/컨버터/안전전원 각 전력 귀환
```

위 DRIVE_BUS의 두 분기는 **모두 K2 하류**이다. 정확한 연결은 W007/W020 및 결선표를 우선한다. 프리차지 경로가 K1/K2를 우회해 열린 비상정지 회로에 동력을 공급하지 않도록 한다. 이 기능 모듈의 내부 저항, 바이패스, 완료 확인, 역방향 회생 호환, 전원 소실 동작은 아직 선정되지 않았다. 컨버터/USB/센서를 프리차지 모터 링크에서 급전하지 않는다.

배터리 양극에 인접한 F0는 차체까지의 무보호 양극 길이를 최소화하는 배치 의도다. 주 퓨즈·분기 퓨즈·홀더·스위치·버스·단자·도체는 배터리 최대 전압, 예상 단락 전류, 기동/스톨 전류, 온도와 시간-전류 특성을 함께 검토한다. 정격 A만 비교해서 고르면 안 된다. DC 차단용량과 제조사 시간-전류 곡선/I²t가 필요하며, 모터 출력 두 선은 어느 쪽도 고정 0V가 아니다.

전선 단면과 퓨즈 정격은 이 패키지에서 확정하지 않았다. 배터리 용량 Ah를 방전 가능 전류 A로 취급하지 않는다. 250W/24V 약 10.42A는 250W를 전기 입력으로 가정했을 때뿐이다. 모터의 250W가 기계출력이면 효율을 고려해야 하고 스톨전류는 별도로 확보해야 한다.

Pololu SMC G2 24v19는 기존 B1 후보를 조건부 유지했다. 제조사 문서의 전압 범위와 전류 표기를 실제 보드의 배선단자·방열 한계와 혼동하지 않는다. 문서에서 포함 단자대에 15A/16A 설명이 혼재하므로 낮은 쪽을 기준으로 검토하고 제조사에 해당 실부품을 확인한다. 이 조건에서 기존 25A 표기 분기 퓨즈를 그대로 승인하지 않았다. [S1]

## 3. 회생과 정지

접촉기 OFF, 배터리 완충, BMS 충전 거부 또는 분기 퓨즈 단선 후에도 바퀴가 모터를 돌려 드라이버 DC 링크에 에너지를 줄 수 있다. 따라서 공용 배터리 버스의 TVS 하나 또는 상류 제동저항만을 해결책으로 두지 않았다. CLL/CLR은 각 드라이버의 퓨즈·프리차지 **하류 로컬 VIN/GND**에 배치한다. 드라이버 자체의 커패시터·보호 기능과 함께 검토한다.

클램프/저항 실모델은 미선정이다. 임계전압과 허용 오버슈트가 배터리 최대 전압과 드라이버 한계 사이에서 동작해야 하고, 저항의 펄스 에너지·연속 전력·온도·화재 분리, 자체 전원, 고장 시 행동을 시험해야 한다. 저항값 하나를 임의로 기입하지 않았다. 전원 OFF 후 잔류전압은 실제로 측정하며 방전 시간의 화면 추정치를 사용하지 않는다.

**전원 차단은 제동이 아니다.** 두 접촉기만으로 경사면 주차, 관성 정지, 전원 소실 제동을 보장하지 않는다. D2에는 선정되지 않은 기계식 브레이크를 안전 장치처럼 그려 넣지 않았다. 하중·속도·경사·전도 조건에 맞는 제동계와 실제 정지거리 시험이 별도로 필요하다. 사람 탑승·공공장소 주행을 승인하지 않는다.

## 4. 비상정지, 재무장, 피드백

DC1은 기존 12V/20A 서보 전원과 다르다. D2에서는 배터리 최저/최고 전압을 수용하고 **정전압 24V**를 내는 buck-boost 공급장치와 이에 맞는 24V 코일/안전릴레이를 제안한다. 배터리 공칭 24V를 안전릴레이에 직결하지 않는다. DC1의 OVP, 부하 급변, 두 코일 동시 투입 전류와 탈락 조건을 확인한다. 정격 출력값은 제조사 열 조건과 함께 선정한다.

S1은 직접 개방 NC 접점 2개를 서로 다른 시험/귀환 채널로 연결한다. SR1은 정확한 제품을 선정해야 하며, 단순 Arduino/ESP32 출력이나 일반 릴레이 모듈이 아니다. 이중 채널, 배선 단락 감시, 감시된 수동 리셋, EDM 기능을 실제 모델의 공식 결선도대로 구성해야 한다. [S8][S9]

S2는 수동 리셋/재무장 입력이다. 비상정지 버튼을 풀거나 전원을 복구하는 것만으로 재기동하면 안 된다. 재무장은 주행 명령과 분리되어야 하고, 고착된 리셋 입력을 정상 재무장으로 취급하지 않는 모델/설정이 필요하다. K1/K2의 검증된 미러 NC 피드백을 직렬로 EDM에 넣는다. 일반 보조접점이라는 이름만 보고 미러 접점으로 취급하지 않는다.

Z1/Z2는 제조사 지정 코일 억제기다. 일반 다이오드로 무검증 대체하면 탈락 시간이 달라질 수 있다. 코일 출력·억제기·SR1 접점 정격·실제 탈락 시간의 조합을 검증한다. 이 배선도는 안전 등급 PL/SIL 또는 특정 정지 범주의 인증을 주장하지 않는다.

## 5. 5V 및 USB 급전

```text
X24 → F4 → DC2 → OV5 → F7 → Orange Pi 전용 전원 입력
                     └─ F8 → 외부전원 USB 허브

Orange Pi HOST → 허브 UP
허브 P1 → ESP32 USB
허브 P2 → C1 USB 어댑터 → C1 OEM 하네스
허브 P3 → UWB 좌측 ranging USB
허브 P4 → UWB 우측 ranging USB
```

OV5는 독립 과전압 차단/역전류 방지 장치라는 기능명이다. 배터리 완충 전압과 예상 과도전압까지의 컨버터 고장 입력을 견디는 실부품을 검증해야 한다. 24V 공칭값만으로 최대 고장 전압을 제한하지 않는다. 트립 임계 상한, 오버슈트, 응답 시간과 하위 부하의 허용값을 함께 검토한다. 5V 레일의 TVS+퓨즈만으로 보드 보호를 승인하지 않는다.

Orange Pi 4 Pro는 정확한 보드·공식 전원 입력·USB-C 요구를 확인해야 한다. 4B/5 등 비슷한 이름의 보드로 몰래 대체하지 않았다. 허브는 upstream VBUS 역급전을 막고 C1 기동 및 전체 포트 전류를 수용하는 실물 제품이어야 한다. USB VBUS 선을 임의 절단하는 방식은 upstream 감지와 열거 실패를 만들 수 있으므로 완성 케이블과 검증된 허브를 사용한다.

ESP32-DevKitC V4 WROOM-32E 38핀은 **허브 USB 하나로만 급전**한다. USB와 5V 헤더 또는 외부 3.3V 전원을 동시에 넣지 않는다. 제조사는 전원 공급 방식의 상호 배타 사용을 명시한다. [S2]

B1의 브레드보드 5V 서보 PWM 버퍼는 기본안에서 제거했다. X3의 3.3V와 0V는 **분리된 두 단자군**이다. 모든 홀이 공통인 버스바/단자 블록에 두 레일을 섞지 않는다. 400접점 브레드보드는 배터리·모터를 분리한 벤치 신호 시험용으로만 남긴다. 이동체에는 잠금 커넥터/압착/절연과 진동 고정을 사용한다.

## 6. UART와 센서

기존 UART 1kΩ 직렬 저항은 완전한 역급전 차단 장치가 아니다. D2는 VCCA=ESP32 3.3V, VCCB=각 드라이버의 확인된 3.3V BEC 패드인 전원 도메인 분리형 UART 모듈 ISOL/ISOR를 제안한다. ISO7721은 검토할 소자 계열이지 임의 보드의 핀번호 확정이 아니다. 완성 모듈의 OFF-state, 초기 논리 상태, 전원시퀀스를 검증한다. 공통 배터리 0V가 있으므로 시스템 전체가 갈바닉 절연되었다고 주장하지 않는다. [S1][S10]

드라이버 VM은 3.3V 전원이 아니다. 드라이버의 BEC 선택 점퍼·3.3V 패드·허용 전류를 확인한다. 주행 전에는 드라이버 설정용 USB를 분리하고, 각 드라이버의 명령 timeout과 safe-start/restart 동작을 반드시 설정·검증한다. ESP32가 멈춘 상태에서도 마지막 주행 명령을 영구 유지하는 설정을 허용하지 않는다. 이 웹페이지는 실제 펌웨어 또는 watchdog을 실행하지 않는다.

BNO085는 Adafruit #4754의 SPI 연결이다. VIN=3.3V, P0/P1=HIGH, SCK/DI/SDA의 SPI 역할을 구분하고 3Vo 출력은 외부 전원에 연결하지 않는다. GPIO34는 입력 전용이며 필요한 INT 풀업은 해당 보드 실장 상태를 확인한다. [S3]

ToF는 Pololu #3415 VL53L1X 2개다. TCA9548A CH0/CH1을 따로 열어 각각 기본 0x29 주소에 접근한다. 두 채널을 동시에 열면 주소 분리 목적을 잃을 수 있다. MUX 주소는 A0/A1/A2=0으로 0x70이다. XSHUT/GPIO1/VDD는 이번 구성에서 NC이며 5V GPIO로 연결하지 않는다. [S4][S5]

TCA9548A는 장거리 버퍼나 절연기가 아니다. 하네스 용량, 상승 시간, 풀업 병렬 합성값, 그라운드 차이와 모터 EMI를 실측한다. 불합격하면 센서 근처 로컬 제어 또는 검증된 전송 확장 구조로 재설계해야 한다. '100kHz로 낮추면 무조건 안전하다' 같은 승인은 하지 않는다.

BU04-Kit의 거리 데이터 USB와 AT/다운로드 포트를 구분한다. 키트 문서의 ⑦ ranging 인터페이스를 기준으로 하며 ⑧ AT 포트로 대체하지 않는다. 두 베이스와 단일 태그의 펌웨어/ID/동시 측정 호환은 별도 검증한다. 태그는 독립 전원이며 카트 전장에 전선을 연결하지 않는다. [S6]

C1 센서와 어댑터는 맞는 OEM 하네스를 사용한다. 포트 순서가 다른 일반 USB-TTL 모듈을 연결하는 도면으로 사용하지 않는다. 상단으로 연장한 USB 케이블의 전압 강하·기동·통신·스트레인 릴리프를 확인한다. [S7]

## 7. 상단 LiDAR와 기구

원본의 스캔 중심 약 0.383m를 제거하고 D2의 스캔 중심을 y=1.15m로 제안했다. 원본의 손잡이 최고점 약 0.983m, 가드 레일 약 0.805m보다 높게 두었다. 마스트, 지지 플레이트, 클램프, USB 어댑터를 함께 표현했다. 이는 원본 사진 기반 비율을 참조한 제안이며 제조용 치수가 아니다. [R1]

높은 수평 스캔은 낮은 박스, 어린이·사람의 자세, 연석, 낮은 구조물 등을 놓칠 수 있고 적재물에 가릴 수 있다. 하향 ToF 2개는 전방 전체 폭의 저상 장애물 검출장치가 아니다. 보완 센서·범퍼와 태그 손실·센서 stale data·MCU 정지 시 실제 정지 기능을 검증한다. 웹의 원반과 선은 설명용이며 실제 라이다 최대 거리/FOV/안전 영역이 아니다.

전장 모듈의 외형과 단자 배열은 실물 CAD가 아니라 참조 형상이다. 트레이/배터리/안전릴레이의 실제 체적과 주변 적재 공간, 압착 공구 접근, 볼트/전선 간섭, 전선 최소 굽힘 반경과 정격 온도, 빗물·먼지·결로·배수·열 방출, 마스트 진동과 전도를 실측한다. 웹 모델에는 자동 간섭 검사·열 해석·구조 해석이 없다.

## 8. 충전과 잔류전압

BT1 CHG+/CHG−는 **실제 BMS 지정 충전 포트의 기능명**이다. 분리형/공통형 BMS에 따라 위치가 다르며 배터리 내부 셀에 직접 접속하라는 뜻이 아니다. S0를 OFF해도 충전 포트까지 격리되는 설계가 아니다. 충전 시에는 구동 전원을 물리적으로 분리하고 충전기와 배터리의 화학계·전압·포트·극성을 대조해야 한다. FCH와 충전 커넥터의 정격 역시 보류다.

## 9. 제작 승인에 필요한 자료

웹 검사 통과, 체크박스 완료, GLB 내보내기는 통전 승인 근거가 아니다. 아래 10개 보류 조건을 실제 부품과 계측 기록으로 해소해야 한다. 어느 항목도 이 패키지에서 자동으로 PASS로 전환되지 않는다.
### G01 배터리·충전기

24V/108Ah라는 명칭만으로 화학계·최대전압·고장전류를 알 수 없음.

**해소 조건:** 모델명, 셀 수, 충전 상한, BMS 방전/충전/회생 허용, 지정 충전 포트, 단락 자료

### G02 구동 드라이버·모터

250W/24V=10.42A는 전기입력 가정일 때의 단순 값. 기계출력 정격이면 효율이 추가됨. 스톨전류는 별개.

**해소 조건:** 브러시 DC 확인, 데이터시트, 부하전류/스톨 한계, 전류제한/가속/열 시험, 단자대 검증

### G03 퓨즈·케이블·단자

임의 25A/30A 표시는 부품 보호를 보장하지 않음.

**해소 조건:** 전선 길이/단면/온도/번들, 전압강하, DC 차단용량, I²t/시간전류 협조, 접점 토크

### G04 비상정지 실모델

SR1·K1/K2는 기능 수준 설계. 모든 제조사 단자 번호를 아직 확정할 수 없음.

**해소 조건:** SR1 공식 결선, 이중 채널/교차단락/EDM/리셋 모드, 미러 NC, 코일 억제/탈락시간, 고장 주입 시험

### G05 회생·프리차지

K1/K2 OFF나 분기 퓨즈 단선 때도 모터는 링크에 에너지를 줄 수 있음.

**해소 조건:** PP/클램프/저항 실모델과 내부 결선, 로컬 링크 연결, 완충/BMS 개방/퓨즈 단선 시 최고전압·온도 시험

### G06 제어전원 보호

5V 컨버터 고장/USB 역급전은 센서를 손상시킬 수 있음.

**해소 조건:** DC1 24V 교체 확정, DC2 부하 급변/열, OV5 고장차단·전압상한, 허브 upstream/포트 전류 시험

### G07 전원 OFF 통신

직렬 저항은 완전한 역급전 차단이 아님.

**해소 조건:** ISO 모듈 OFF-state/시퀀스 검증, USB 단일 급전, 3V3 총전류, 각 모터 드라이버 command-timeout 설정/시험, UART startup/재기동, I²C 상승시간·SPI 신호·EMI 시험

### G08 기계적 제동

전원 차단은 브레이크가 아니며 카트가 관성·경사로 움직일 수 있음.

**해소 조건:** 하중/속도/경사 기반 제동계 선정, 전원 상실 제동·주차 유지, 정지거리/전도 검증; 탑승 불허

### G09 마스트·배선 실측

원본은 사진 기반 모델로 실제 부품 체적과 케이블 길이를 확정하지 못함.

**해소 조건:** 배터리/접촉기 실측, 구조/하중, 적재공간, 케이블 최소 굽힘/클램프, 방수·방진·차체 간섭

### G10 상단 스캔 사각·센서 고장

높은 수평 라이다와 하향 ToF 2개만으로 낮은 장애물·사람·계단을 모두 감지하지 못함.

**해소 조건:** 낮은 장애물 보완 감지/범퍼 검토, 적재 가림, 낙차/태그 손실/시간초과/MCU 정지의 실제 정지 시험

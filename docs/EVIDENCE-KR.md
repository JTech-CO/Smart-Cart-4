## 값이 충돌하는 부분

[기계 판독 근거표](../data/evidence-register.json)에 본문 서보 52×30×65mm, 사진 65.39/48.10/62.17mm, 리드 320/307mm, JST-ZHR/JR 3핀 표기, 모터 출력축 44/45mm, 원본과 D4 적재판 치수를 따로 보존했습니다. 하나의 정확한 제작 치수로 통합하지 않았습니다. 3D 서보 외피 65.39×30×48.10mm는 모델링 선택값이며 실측 승인이 아닙니다.

사진의 PWM 3.3~5V·500~2500µs 표기와 실제 입력 HIGH 보증값·전원 범위는 구분해야 합니다. 기본 50Hz·1500µs에서 제한 범위로 시험하는 제안은 제어 펌웨어의 구현 완료를 뜻하지 않습니다.

## 복구한 사진

`assets/reference/doc-01.webp`~`doc-14.webp`는 첨부 DOCX의 이미지 등장 순서에서 추출했습니다. `servo-*.webp` 4개는 사용자 제공 사진입니다. 원문 DOCX는 수정하지 않았으며, 이미지 추출 목록과 원본 SHA-256은 [input-manifest.json](input-manifest.json)에 기록했습니다. 원본의 워터마크나 제품 표기는 제거하지 않았습니다. 이미지의 제3자 권리를 새로 부여하지 않습니다.

# 실물 시험 준비 목록

아래는 실행된 시험 결과가 아니라 담당자가 기록해야 할 항목입니다. 전장 책임자의 감독과 부품 사양 검토가 선행되어야 합니다. 승차/경사로 시험을 승인하지 않습니다.

## T01 배터리와 IBT-2 전압 부적합

JDRV OPEN 유지. 배터리 상한/회생 여유를 검증한 호환 전원 또는 드라이버 변경 승인. 단순 과전압 차단기만으로 호환되지 않음.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T02 구동모터·IBT-2 열/전류 정격

기동/부하전류, 단자/PCB/방열 온도, 퓨즈시간-전류 및 차단용량 검증.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T03 실물 단자 확인

무전원 도통검사, 실제 보드 앞뒤사진/회로 대조. 의심GND사용금지. IS ADC미연결.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T04 부팅·전원 순서·PWM/EN

/OE 기본HIGH, EN기본LOW, RPWM/LPWM초기LOW, 소프트웨어timeout/재부팅/USB분리 시험. 양방향PWM 동시명령 금지.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T05 서보 실모델·배선·기구 끝점

10~12.6V실품확인, 커넥터정격/전류실측, 좌우각교정 및 기계적멈춤. 서보축으로 차중지지금지.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T06 회생·잔류전압·제동

로컬DC링크 흡수에너지/트립전압/냉각, 정지거리, 기계브레이크 검증. 승차/경사시험금지.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T07 안전정지 부품 선정

2채널NC, 수동리셋, EDM NC미러접점, DC차단 정격/코일전압/억제기 시험.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T08 5V·USB·LiDAR 기동

C1센서단 전압/리플≤150mV, 허브역급전/과전류/포트별전원 시험; USB와헤더중복급전금지.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T09 기구 치수 충돌

실물측정후장착홀/스플라인/허브/브래킷 확정. C1M2.5내부진입≤4mm.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T10 센서 가림·낙차 감지

장애물높이/검은물체/유리/태그상실테스트. BU03/BU04펌웨어호환 및 RF안테나간섭 확인.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.

## T11 FreeCAD 원본과 D4 형상

원본군은변경없이숨겨보존. D4재구성은별도그룹이며용접/구조/간섭설계승인이아님.

기록: 측정값 / 계측기 / 시험 조건 / 담당자 / 일시 / 합격 근거.
